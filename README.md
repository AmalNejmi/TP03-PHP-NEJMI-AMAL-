# TP03-PHP-NEJMI-AMAL-
# TP 3 PHP : Suivi des notes des apprenants

**Auteur :** Amal Nejmi

## Objectif
Créer une mini-application PHP pour saisir, enregistrer,
afficher et analyser les notes des apprenants.

## Technologies
- PHP
- HTML
- XAMPP
- Git et GitHub

## Lancement
1. Copier le dossier dans C:\xampp\htdocs\tp_php.
2. Démarrer Apache dans XAMPP.
3. Ouvrir http://localhost:8000/exo1_bases.php .

## Fonctionnalités
- Variables, constantes et types
- Conditions et boucles
- Tableaux et statistiques
- Formulaires GET et POST
- Enregistrement CSV et export JSON
- Sessions, cookies et dates
